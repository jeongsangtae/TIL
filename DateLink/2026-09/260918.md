# 오늘 한 일

## 커밋한 내용

- Render에 배포한 프론트엔드와 백엔드 확인 및 수정

## 수정 내용

- Render 프론트엔드 환경 변수에 VITE_API_URL 항목을 추가하고 백엔드 경로 추가해 연결
- Render 프론트엔드 Redirects/Rewrites 부분에 내용 추가
- Render 백엔드 환경 변수에 NODE_ENV 항목을 production으로 수정해 오류 수정
- 백엔드에서 구성한 프론트엔드 정적 파일 제공하는 내용과 SPA 라우팅 관련 내용, 존재하지 않는 경로와 전역 서버 오류 처리 내용 수정

## 결과

- Render에 배포한 프론트엔드와 백엔드가 연결되어 배포한 사이트 이동 후 회원가입 및 로그인 시 문제없이 진행되며 그룹 채팅방 생성까지 되는 것을 확인
- 추가로 그룹 채팅방에 입력한 메시지도 출력되어 보여지는 것을 확인
- 관련 정보들이 MongoDB Atlas에 모두 저장되는 것을 확인
