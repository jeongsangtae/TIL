# 오늘 배운 점

- Node 버전과 Electron 버전이 호환되지 않는 것을 확인하고 Node 버전을 업데이트하며 수정해주었는데 Node 버전 수정하는 방법을 이전에는 이번보다 더 복잡하게 처리했던 것 같은데 이번에는 비교적 조금 더 쉽게 처리할 수 있었던 것 같다.
- Electron이 로컬에서 문제없이 실행되는 것은 좋은 소식이지만 이걸 배포해 사용하도록 하는 부분은 처음 시도하는 방법이라서 조금 어려울 것으로 생각이 되며, 어떤 구조로 처리되어 사용하는지 배포한 뒤 정리할 생각이다.
