# 오늘 배운 점

- 정적 파일 관련 오류가 발생한 이유는 path 내용을 주석 처리한 상태로 사용하려고 해서 오류가 발생했던 것이며 현재는 프론트엔드와 백엔드를 나눈 상태로 작업했기 때문에 굳이 정적 파일 관련 내용을 사용할 필요가 없어 삭제하는 것으로 정리해주었다.
- 배포와 관련된 내용을 파일별로 나눠 정리해 다른 프로젝트 배포 시에 다시 참고할 수 있도록 해주었는데 이렇게 한 번 정리해놓으면 기본 틀에서 약간의 수정만으로 쉽게 배포할 수 있다고 생각된다.
