# 오늘 한 일

## 커밋한 내용

- Render 배포 테스트

## 수정 내용

- Render에 배포한 프론트엔드와 프로젝트 깃 허브 연결 확인을 위해 로그인 페이지와 App 파일 간단하게 수정

## 결과

- 웹 URL로 연결한 상태에서 커밋한 후 Render에 배포한 프론트엔드 내용을 확인하면 실시간 배포가 되지 않는 것을 확인
- 웹 URL이 아닌 깃 레포지토리와 직접 연결한 상태로 다시 테스트해 확인한 결과 커밋하면 즉시 배포되는 것을 확인

## Commit 링크

- 커밋은 했으나 테스트를 위한 내용이므로 링크 추가하지 않음

<br />

# 오늘 배운 점

- 웹 URL로 연결하는 방식은 처음 사용한 방식인데 이 방식으로 진행하면 커밋한 후 수동으로 배포를 다시 진행해야 하는 번거로움이 있기 때문에 깃 레포지토리로 연결하는 방식을 사용해 커밋 즉시 바로 배포되는 방식이 더 적절한 방법인 것을 알게 되었다.
- 프론트엔드 사이트 배포할 때 배포하려는 프로젝트가 깃 레포지토리에서 보이지 않아서 웹 URL로 진행했었는데 찾아보니 따로 허용을 해줘야 연결할 수 있는 것을 알게 되어서 앞으로 잊지 않고 미리 연결할 수 있도록 허용해 문제가 생기지 않도록 해줄 생각이다.
