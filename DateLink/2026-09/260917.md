# 오늘 배운 점

- 이전에 프로젝트 배포할 때처럼 MongoDB Atlas에 프로젝트를 추가하고 Render에 배포한 백엔드와 연결해 테스트해봤지만 회원가입도 제대로 되지 않고, 로그인도 제대로 되지 않는 문제가 발생해서 어느 부분이 잘못되었는 지 다시 확인해 볼 필요성을 느꼈다.
- 현재 기억나는 것으로는 URI 관련 설정 같은 내용을 추가로 수정해야 했던 것 같은데 이전에 Render에 배포한 프로젝트를 다시 살펴보며 추가 수정해줘야 하고 오랜만에 배포하는데 쉽지 않다고 다시 한 번 느꼈던 것 같다.
