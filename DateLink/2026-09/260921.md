# 오늘 한 일

## 커밋한 내용

- Render에 배포한 사이트 기능 테스트 및 그룹 멤버 메뉴 밑줄 오류 수정

## 수정 내용

- 시크릿 모드 로그인 오류 테스트
- Edge를 통해 다른 계정으로 로그인해 온라인/오프라인 및 실시간 반영 테스트
- 관리자 권한으로 호스트 우클릭 시에 밑줄 보이는 내용 수정

## 결과

- 시크릿 모드에서 로그인할 때 발생하는 오류는 해결하지 못했고 대신 Edge를 사용해 다른 계정으로 로그인해 테스트하지 못한 기능 테스트
- 관리자 권한으로 호스트 우클릭 시에 버튼이 보여지지 않는 상태로 밑줄이 보여졌으나 내용 수정으로 인해 밑줄도 보이지 않는 것을 확인

# 오늘 배운 점

- 시크릿 모드에서 로그인 오류가 발생하는 문제는 얼추 찾긴 했지만 이걸 해결하기 위해 로직을 수정하기에는 애매했고 굳이 여기에 집착하는 것보다 차라리 Edge 같은 다른 브라우저로 테스트하는 방향이 맞다고 생각되어 시크릿 모드 문제는 일단 보류하고 Edge 같은 다른 브라우저로 테스트해 기능이 모두 올바르게 작동하는 것을 확인했다.
- Edge 같은 다른 브라우저에서도 문제가 없는지 추가로 확인해주는 것이 좋아보임
