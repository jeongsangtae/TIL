# 오늘 배운 점

- 기존에 구성된 Electron 관련 내용을 사용해 조건부를 구성하는 것이 아닌 브라우저 화면 너비를 판단하는 내용을 추가해 조건부로 사용해 테스트해본 결과, 처음에는 생각한대로 동작하는 것 같았지만 화면 너비를 늘리고 다시 좁히며 테스트해보니 제대로 작동하지 않는 문제가 발생했는데 새로운 방식을 시도하다보니 약간의 문제가 생긴 것 같기에 추가 수정할 예정
- 브라우저 화면 너비가 960xp 이상일 때 동작하는 내용을 추가하거나 기존 방식을 다시 구성해 조건부로 테스트해볼 생각이긴 하지만, 더 좋은 방법이 있는지 확인한 뒤 최대한 간결한 방식으로 구성할 예정

<br />

# 내일 할 일

- 화면 좌우가 좁혀질 때 사용자 정보 내용이 아바타만 보여지도록 수정 필요
- 좁아진 상태에서 아바타 클릭 시에 위로 내용이 펼쳐져 설정과 로그아웃 버튼 등 내용이 보여지도록 구성 필요
- 화면이 좌우로 좁혀질 때 글자 크기나 내용들이 그대로 유지되어 보여지는 부분 수정 필요 (반응형 관련)
- div 태그 같은 내용이 자동완성되지 않는 부분과 저장 시 줄 바꿈이 약간 어색한 부분 수정 필요
- Electron 관련 따로 구성한 파일 다시 확인 필요
- Electron에 추가된 최상단 내용으로 인해 틀어지는 부분이 있는지 확인 필요
