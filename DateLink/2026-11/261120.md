## 커밋한 내용

## 수정 내용

- className에 구성된 조건부 내용을 삭제하고 별도의 className을 구성

- 사용자 정보와 메뉴 관련 CSS 수정

- 밑줄을 추가했으나 보이지 않는 것을 확인

- 사용자 메뉴가 이전보다 좀 더 자연스럽게 보이는 것을 확인

# 오늘 배운 점

- 밑줄 내용을 추가했으나 기존 UI와 다르게 보이지 않는 문제가 왜 갑자기 발생했는지 확인이 필요하고 사용자 메뉴가 이전보다 좀 더 자연스럽게 보여지고 있긴 하지만 약간 부족한 부분들이 있기 때문에 이에 대해 추가 수정할 예정

<br />

# 내일 할 일

- 사용자 메뉴에 추가한 밑줄 보여지도록 수정 필요
- 사용자 메뉴가 열린 상태에서 화면 크기가 커지고 다시 작아질 경우 닫힌 상태로 보여지도록 수정 필요
- 작아진 사용자 정보 내의 아바타와 사용자 메뉴 관련 UI 수정 필요 (사용자 아바타 망가짐 문제)
- 화면이 좌우로 좁혀질 때 글자 크기나 내용들이 그대로 유지되어 보여지는 부분 수정 필요 (반응형 관련)
- div 태그 같은 내용이 자동완성되지 않는 부분과 저장 시 줄 바꿈이 약간 어색한 부분 수정 필요
- Electron 관련 따로 구성한 파일 다시 확인 필요
- Electron에 추가된 최상단 내용으로 인해 틀어지는 부분이 있는지 확인 필요
