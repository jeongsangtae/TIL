## 수정 내용

- JSX 코드에 주석 처리된 아바타 내용 삭제
- 이전에 구성한 사용자 메뉴 관련 CSS 삭제
- 좁은 화면에서 아바타에 커서를 올리면 포인터로 바뀌고 약간의 효과가 적용되도록 CSS 추가

- 작은 화면에서 아바타에 커서를 올리면 약간의 강조 효과와 함께 커서가 변경되는 것을 확인

# 오늘 배운 점

- 작은 화면에서 사용자 메뉴를 열고 큰 화면으로 변경한 뒤 다시 작은 화면으로 돌아올 때 자동으로 닫히도록 내용을 추가했는데 이 때 구성한 내용에 대해 추가 이해가 필요한 상황으로 이전에 사용자 메뉴를 여는 버튼 조건과 유사하게 구성을 하긴 했지만 약간 헷갈리는 부분이 있기에 추가 확인을 진행할 예정
- 이번에 CSS뿐만이 아닌 프론트엔드에서 미디어 쿼리 조건을 추가해 구성한 뒤 사용해본 결과, 화면 크기를 감지해 로직을 직접 제어하고 즉시 대응할 수 있다는 것을 알게 됨
