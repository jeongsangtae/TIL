# 오늘 한 일

## 커밋한 내용

- Electron 다이렉트 채팅방, 그룹 채팅방 서브 사이드바 스크롤 CSS 수정 (테스트)

## 수정 내용

- 다이렉트 채팅방과 그룹 채팅방 서브 사이드바에서 보여지는 스크롤 바 간격이나 위치 관련 CSS 수정
- 추가로 하단이 잘리지 않도록 수정

## 결과

- 스크롤 바가 잘리지 않은 상태로 보여지는 것은 문제가 없지만 다이렉트 채팅방 서브 사이드바에서 보여지는 스크롤 바는 간격이 약간 어색

# 오늘 배운 점

- 다른 내용에서 구성한 스크롤 바는 간격이나 위치가 딱히 문제가 되지 않았지만 서브 사이드바에서 구성한 스크롤 바는 옆에 다른 내용때문인지 적절한 간격이 잡히지 않는 문제가 발생해 이 부분에 대한 추가 수정이 필요한데, 그룹 채팅방 목록처럼 스크롤 바가 보이지 않는 상태로 움직이는 것도 괜찮다는 생각이 들어 이 방법을 테스트해볼 예정
