# 오늘 한 일

## 커밋한 내용

- Electron 그룹 채팅방 서브 사이드바 스크롤 추가 및 스크롤 CSS 추가

## 수정 내용

- Electron 다이렉트 채팅방, 그룹 채팅방 하단 간격 테스트
- Electron 그룹 채팅방 서브 사이드바에 스크롤이 보여지도록 구성하고 관련 CSS 추가

## 결과

- Electron 다이렉트 채팅방과 그룹 채팅방 하단 간격을 수정한 내용이 사용자 정보와 한 줄로 보여져 약간 더 자연스러운 것을 확인 (테스트만 하고 주석 처리)
- Electron 그룹 채팅방 서브 사이드바에서 사용자가 많아질 경우 스크롤이 생겨나고 아래가 잘리지 않도록 구성된 것을 확인

# 오늘 배운 점

- Electron 다이렉트 채팅방과 그룹 채팅방 하단 간격을 수정한 내용이 약간 더 자연스러운 것 같으면서 부자연스러운 느낌이 들어서 좀 더 테스트를 해봐야 할 것 같고, 그룹 채팅방 서브 사이드바에 생긴 스크롤은 잘리는 문제 같은건 없으나 추가된 스크롤로 인해 약간 UI가 부자연스럽기 때문에 추가 수정이 필요한 상황인데 CSS 내용을 추가하면서 적절한 간격 조절이 매번 쉽지 않다고 느껴지기에 이 부분은 좀 더 감각이 필요하다고 생각됨

<br />

# 내일 할 일

- Electron 환경에서 위아래로 길이가 줄어들 때 그룹 채팅방 서브 사이드바에서 스크롤이 생기지만 약간 UI가 이상해지므로 확인 필요
- Electron 환경에서 좌우 크기가 줄어들 경우 다이렉트 채팅방 서브 사이드바 스크롤이 제대로 작동하지 않는 문제 수정 필요
- Electron 좌우 길이가 일정 크기로 줄어들 때 채팅방 내에서 새로운 메시지 추가 버튼 오른쪽 하단과 왼쪽 하단 테두리 CSS가 풀리는 문제 수정 필요
- Electron 관련 따로 구성한 파일 다시 확인 필요
- Electron에 추가된 최상단 내용으로 인해 틀어지는 부분이 있는지 확인 필요
