# 오늘 한 일

## 커밋한 내용

- Electron 앱 에러 수정 및 설치 파일 배포

## 수정 내용

- README 파일에 Electron 데스크톱 앱 다운로드 링크 및 방법 추가
- main.cjs 파일 내의 내용에서 loadFile로 된 부분을 loadURL로 수정하고 프론트엔드 주소로 구성
- Electron 설치 파일 배포를 위해 build하고 package.json 내의 version 수정
- 깃 허브 내에 release 추가와 설치 파일 배포

## 결과

- README 내용에 깃 허브 Electron 데스크톱 앱 다운로드 링크가 보여져 바로 이동 가능한 것을 확인
- loadURL로 수정하고 프론트엔드 주소로 설정되면서 데스크톱 앱에서 실행한 Electron이 문제없이 작동하는 것을 확인
- 깃 허브 release 내용에 Electron 설치 파일이 보여져 클릭 시 다운로드 되는 것을 확인
- 이 외에 테스트 진행 중 홈 화면이 아닌 다른 화면에서 새로고침 시에 오류와 함께 흰 화면만 보여지는 문제가 발생하기 때문에 해당 내용 수정 필요
