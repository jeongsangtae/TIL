# 오늘 한 일

## 커밋한 내용

- Electron 최상단 더블 클릭 최대화 관련 로직 삭제 및 다이렉트 채팅방 패널, 그룹 채팅방 패널 반응형 CSS 추가

## 수정 내용

- Electron 최상단 더블 클릭 시 최대화되는 내용과 드래그 관련 좌표 내용 모두 삭제
- 다이렉트 채팅방 패널과 그룹 채팅방 패널 CSS에 미디어 쿼리 내용 추가

## 결과

- Electron 드래그 시 2초정도 뒤에 다른 창이 모두 내려가는 문제는 Window 자체 기능으로 Electron 문제가 아닌 것으로 확인
- Electron 최상단 더블 클릭 시에 최대화되지 않는 것을 확인
- Electron 드래그 시에 문제없이 드래그되는 것을 확인
- Electron 좌우 크기를 일정 크기 이하로 줄이면 다이렉트 채팅방 패널 또는 그룹 채팅방 패널이 보이지 않게 되어 채팅 내용이 잘리지 않는 것을 확인

# 오늘 배운 점

- Electron 드래그 시 2초정도 뒤에 다른 창이 모두 내려가는 문제가 발생해서 Electron 드래그 관련 내용을 구성하면서 발생한 문제로 생각했으나, 해당 기능은 Window 자체 기능으로 확인이 됐으며 비활성화도 할 수 있었지만 현재는 비활성화할 필요성을 느끼지 못해서 테스트만 하고 현재 상태 그대로 놔두었다.
- Electron 좌우 크기를 줄였을 때 각 채팅방 패널들이 사라져 채팅방이 잘리지 않도록 구성을 해주었는데 이 때 미디어 쿼리 관련 복잡한 구성이 필요하다고 생각했으나 단순히 패널들이 보이지 않도록 해주면 채팅방이 넓어져 문제가 해결되는 것을 파악했고 이와 유사하게 더 작아진 화면에서도 마찬가지로 채팅방이 잘릴 경우 서브 사이드바가 보이지 않도록 해주면 해결될 것으로 생각된다.

<br />

# 내일 할 일

- Electron 환경에서 위아래로 길이가 줄어들 때 사이드바는 스크롤이 생기지 않고, 패널은 스크롤이 생기지만 잘리는 문제 수정 필요
- Electron 환경에서 좌우 크기가 줄어들 경우 다이렉트 채팅방 서브 사이드바에서 사용자 정보 위로 내용이 보여지는 문제 수정 필요
- Electron 좌우 길이가 일정 크기로 줄어들 때 채팅방 내에서 새로운 메시지 추가 버튼 오른쪽 하단과 왼쪽 하단 테두리 CSS가 풀리는 문제 수정 필요
- Electron 전체 테두리 구분을 위해 구분선 추가 필요
- Electron 관련 따로 구성한 파일 다시 확인 필요
- Electron에 추가된 최상단 내용으로 인해 틀어지는 부분이 있는지 확인 필요
