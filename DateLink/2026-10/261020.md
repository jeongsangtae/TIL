# 오늘 한 일

## 커밋한 내용

- Electron 레이아웃 테두리, 다이렉트 채팅방 서브 사이드바, 다이렉트 채팅방 패널, 그룹 채팅방 패널 CSS 수정

## 수정 내용

- Electron 다이렉트 채팅방 패널, 그룹 채팅방 패널 하단 공간 수정
- Electron 다이렉트 채팅방 서브 사이드바가 사용자 정보 위로 보이지 않도록 수정
- Electron 환경에서 레이아웃 테두리 선이 보여지도록 수정

## 결과

- 다이렉트 채팅방 패널과 그룹 채팅방 패널 하단에 공간이 생겨 내용이 잘리지 않는 것을 확인
- 다이렉트 채팅방 서브 사이드바가 사용자 정보 뒤로 보여져 스크롤해도 위로 튀어나오지 않는 것을 확인
- Electron 환경에서 레이아웃 테두리에 선이 보여져 다른 내용과 구분되는 것을 확인

# 오늘 배운 점

- Electron 최상단에 한 줄이 추가되면서 여러 내용들 간격이 조금씩 틀어진 것 같은데 이로 인해 수정을 해주긴 했지만 아직 추가로 수정이 필요한 부분이 남아서 이 부분들에 대한 추가 수정을 해줄 예정이며, 이렇게 추가되는 내용으로 인해 여러 내용이 한 번에 틀어지는데 이 부분은 추가로 미리 예방 조치가 가능한 지 확인해볼 예정

<br />

# 내일 할 일

- Electron 환경에서 위아래로 길이가 줄어들 때 그룹 채팅방 서브 사이드바에서 스크롤 생기지 않는 문제 수정 필요
- Electron 환경에서 좌우 크기가 줄어들 경우 다이렉트 채팅방 서브 사이드바 스크롤이 제대로 작동하지 않는 문제 수정 필요
- Electron 좌우 길이가 일정 크기로 줄어들 때 채팅방 내에서 새로운 메시지 추가 버튼 오른쪽 하단과 왼쪽 하단 테두리 CSS가 풀리는 문제 수정 필요
- Electron 관련 따로 구성한 파일 다시 확인 필요
- Electron에 추가된 최상단 내용으로 인해 틀어지는 부분이 있는지 확인 필요
