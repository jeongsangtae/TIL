# 오늘 한 일

## 커밋한 내용

- Electron 관련 다이렉트 채팅방과 그룹 채팅방 잘리는 문제 수정

## 수정 내용

- 다이렉트 채팅방과 그룹 채팅방 세부 내용에 electron 관련 조건부 추가하고 JSX 코드에 적용
- 다이렉트 채팅방과 그룹 채팅방 세부 내용 CSS 파일에 아래 간격이 늘어나도록 수정

## 결과

- 다이렉트 채팅방과 그룹 채팅방 내의 채팅 입력창이 위로 올라와 잘리지 않은 상태로 보여지는 것을 확인
