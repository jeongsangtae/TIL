# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 세부 내용 컨텍스트 메뉴 출력 관련 내용 추가 및 그룹 멤버 관련 타입 에러 수정 및 그룹 멤버 메뉴 기본 구성 추가

## 수정 내용

- 그룹 채팅방 세부 내용에 그룹 멤버 메뉴 관련 내용을 추가하고 여러 props 내용 전달
- 그룹 채팅 사용자 목록, 사용자, 패널에 구성된 주석 처리된 내용 모두 삭제
- 그룹 멤버 메뉴 기본 구조와 CSS 추가
- 재사용 타입에 구성된 기존 수정 및 새로운 타입 추가

## 결과

- 그룹 채팅방 내의 사용자 우클릭 시에 메뉴가 열리고 사용자 아바타와 닉네임 등 내용이 보여짐
- 여러 타입 에러가 사라진 것을 확인
