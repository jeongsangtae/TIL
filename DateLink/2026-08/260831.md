# 오늘 배운 점

- CSS 내용을 테스트할 때 li 관련 구성을 추가했었는데 이 때 li 자체에 스타일을 추가한 내용으로 인해 다른 li가 사용되는 부분에서도 구성한 CSS가 적용되어 UI가 깨지는 문제가 발생하는 것을 확인했기 때문에 앞으로 구성할 때는 컴포넌트 범위에서 만나는 모든 요소에 적용되는 것까지 고려해 li처럼 사용하는 것이 아닌 className을 각각 구성하는 것이 좋다고 생각된다.
