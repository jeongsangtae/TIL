# 오늘 한 일

## 커밋한 내용

- 그룹 채팅방 목록 컬렉션 사용하는 여러 내용 수정 및 그룹 채팅 데이터 관련 타입 수정 및 타입 에러 수정

## 수정 내용

- 백엔드 내의 그룹 채팅방 목록 컬렉션 사용하는 내용 수정
- 그룹 채팅방 추가 시에 role 항목을 함께 추가하고 "host"로 설정되도록 구성
- 그룹 채팅방 초대 수락 시에 role 항목이 함께 추가되고 "member"로 설정되도록 구성
- 프론트엔드에서 함께 참여한 그룹 채팅방 목록을 반환하는 내용 수정
- 그룹 채팅 데이터 타입 정의 수정 및 그룹 멤버와 그룹 멤버 역할 관련 타입 정의 추가

## 결과

- 그룹 채팅방 생성 시에 생성한 사용자 역할은 "host"로 설정되어 DB에 저장되는 것을 확인
- 그룹 채팅방 초대 수락 시에 수락한 사용자 역할은 "member"로 설정되어 DB에 저장되는 것을 확인
- 수정 및 추가된 타입 정의로 인해 타입 에러가 사라진 것을 확인
- 그룹 채팅방 목록 컬렉션이 사용된 부분에서 내용이 약간씩 수정되어 이전과 동일한 방식으로 처리되는 것을 확인

# 오늘 배운 점

- 그룹 채팅방 목록 컬렉션을 사용하는 곳이 많아 수정 범위가 예상보다 넓었는데, 앞으로는 최대한 한곳에서 관리하는 구조를 더 고려해야겠다고 느낌
- 사용자 역할을 미리 데이터 구조에 포함해두니 이후 권한 관리 기능을 훨씬 자연스럽게 확장할 수 있다는 점을 알게 됨
- 기능을 먼저 구현하기보다 데이터 구조를 먼저 설계하는 것이 이후 기능 확장에 훨씬 유리하다는 것을 다시 느낌
- 새로운 기능 하나를 추가하더라도 관련된 타입과 API, 프론트엔드, 백엔드를 함께 확인해야 한다는 점을 다시 느낌
