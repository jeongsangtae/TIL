# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 호스트 권한 위임 관련 백엔드 로직 추가 및 호스트 권한 위임 액션 함수 수정

## 수정 내용

- 호스트 권한 위임하는 액션 함수에서 방 번호를 params로 전달하도록 수정
- 백엔드에 호스트 권한 위임 관련 라우터를 추가
- 호스트 권한 위임 라우터에 그룹 채팅방 찾는 내용, 선택한 사용자 찾는 내용, 호스트 권한 위임하는 내용 구성

## 결과

- 호스트 권한 위임 버튼 클릭 시에 선택한 사용자가 호스트가 되며 공지사항 수정 및 삭제 그리고 채팅방 삭제까지 할 수 있게 됨
- DB에서 호스트 관련 정보까지 모두 변경된 것을 확인

# 오늘 배운 점

- 방 번호같은 정보는 요청 내용으로 전달하지 않고 API 내용에 포함시켜 전달하는 방향이 훨씬 간편하고 처리하기 쉽다는 것을 배움
- 호스트 권한 위임을 하기 위해 백엔드에서 일치하는 그룹 채팅방, 사용자 등 여러 내용을 확인해야 할 부분이 많다고 느낌
- MongoDB에서 배열로 된 내용의 일부 필드를 한 번에 업데이트할 때 arrayFilters 같은 내용을 사용하는데 이 내용을 저번에도 사용하긴 했지만 완벽히 이해한 느낌이 아니었는데 이번에 다시 사용하고 설명을 보면서 구조를 제대로 이해할 수 있게 되었음
