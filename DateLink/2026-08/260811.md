## 수정 내용

- 관리자 권한 부여 관련 액션 함수와 확인창 함수 연결
- 그룹 채팅방 패널에 그룹 채팅방에 참여한 사용자 목록을 전달하고 그룹 채팅 사용자 정보와 사용자 역할 정보를 결합
- 사용자 역할 정보를 사용해 공지사항 수정과 삭제 조건부 수정 및 아이콘 조건부 수정
- 타입 정의 수정

## 결과

- 관리자 권한 부여 시 호스트 위임이 아닌 관리자 권한 부여되는 것을 확인
- 관리자 권한인 사용자 화면에서 공지사항 수정과 삭제 버튼이 보여지는 것을 확인
- 관리자인 사용자가 공지사항 수정 버튼 클릭 시에 수정창이 열리고 수정 시에 에러가 뜨는 기 때문에 추가 수정 필요
- 그룹 채팅방 패널에서 관리자 권한인 사용자는 방패 모양 아이콘으로 표시되는 것을 확인
