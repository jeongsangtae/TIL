## 수정 내용

## 결과

- 관리자 권한으로 공지사항 수정, 삭제 시 오류없이 진행되는 것을 확인

# 오늘 배운 점

- 백엔드 라우터를 구성할 때도 비슷한 로직을 가져와 구성하는데 이 때, 중요한 부분만 수정하고 일부 내용은 놓치는 상황이 발생했는데 이런 상황이 발생하지 않도록 전체적으로 로직을 잘 확인하고 사용해야 한다고 느낌
- 아이콘을 사용할 때 기능에 초점을 둘 지 또는 UI에 초점을 둘 지 정해야 하는데 이 부분은 두 내용을 모두 챙길 수 있으면 좋고 우선이 되어야 하는건 사용자가 해당 기능이 무엇인지 알 수 있도록 하는 것이 우선이라는 것을 알게 됨
