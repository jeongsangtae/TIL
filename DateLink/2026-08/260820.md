# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 사용자 강제 퇴장 관련 에러 수정 및 그룹 채팅 멤버 메뉴 관련 에러 확인

## 수정 내용

- 그룹 채팅 사용자 강제 퇴장 관련 백엔드 소켓 이벤트와 프론트엔드 소켓 이벤트 수정
- 그룹 채팅 사용자 강제 퇴장 관련 useEffect 수정
- 그룹 채팅 사용자 메뉴 클릭 시 보여지는 데이터 확인을 위한 콘솔 로그 추가

## 결과

- 사용자가 강제 퇴장 당할 때 해당 채팅방 화면이 보여질 경우 홈으로 이동되는 것을 확인
- 사용자가 강제 퇴장 당할 때 다른 채팅방에 있을 경우 사용자 목록에서 사라지지않고 그대로 유지되는 것을 확인
- 사용자가 강제 퇴장 당할 때 어떤 화면이든지 해당 채팅방이 채팅방 목록에서 사라지는 것을 확인
- 사용자가 채팅방에 들어온 후 사용자 메뉴에서 호스트 권한 위임을 제외한 버튼이 보이지 않는 것을 확인
