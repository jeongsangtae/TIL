# 오늘 한 일

## 커밋한 내용

- 호스트 그룹 채팅 나가기 관련 확인 모달 수정, 로직 추가

## 수정 내용

- 그룹 채팅 나가기 버튼 모든 사용자 가능하도록 수정
- 그룹 채팅 나가기 버튼 클릭 시 사용자 ID와 역할을 함께 전달하도록 수정
- 호스트가 그룹 채팅 나가기 버튼 클릭 시 자신을 제외한 사용자 목록이 보여지며 호스트를 넘길 사용자 선택할 수 있도록 구성
- 사용자 목록에서 원하는 사용자만 따로 찾도록 검색 기능 추가

## 결과

- 호스트가 그룹 채팅방 우클릭 시 그룹 채팅 나가기 버튼이 보여지는 것을 확인
- 그룹 채팅 나가기 버튼 클릭 시 검색창과 사용자 목록이 보여지며 사용자 닉네임 또는 이메일 입력 시 검색한 사용자 목록만 보여지는 것을 확인
