# 오늘 한 일

## 커밋한 내용

- 그룹 멤버 액션 확인창 관련 내용 추가 및 그룹 멤버 액션 관련 함수, 버튼 수정 및 여러 내용 추가 수정

## 수정 내용

- 그룹 멤버 메뉴에 구성된 여러 버튼 클릭할 수 있도록 수정
- 호스트 권한 위임 관련 함수를 토글 모달에 전달한 뒤 액션 함수에 관련 데이터를 전달하도록 수정
- 관리자 권한 부여, 회수, 사용자 강제 퇴장 함수를 호스트 권한 위임 함수와 유사하게 구성
- 그룹 채팅방 세부 내용에서 그룹 멤버 액션 확인창이 열리도록 구성
- 그룹 멤버 액션 확인창에 함수를 추가해 토글 모달 데이터를 전달받아 액션 함수에 관련 데이터를 전달하도록 구성 및 타입을 확인해 그에 맞는 문구와 버튼이 보여지도록 구성
- 그룹 멤버 액션 확인창 CSS 추가
- 여러 타입을 수정해 타입 에러 해결

## 결과

- 호스트 권한 위임 버튼 클릭 시에 확인창이 뜨고 확인창에서 위임 버튼을 클릭해야 작동하는 것을 확인
- 관리자 권한 부여, 회수, 사용자 강제 퇴장 버튼 클릭 시에 확인창이 뜨는 것을 확인
- 각 버튼 클릭 시에 내용에 맞는 문구가 출력되는 것을 확인
- 타입 에러없이 ESLint 모두 통과되는 것을 확인

# 오늘 배운 점

- 기존에 만들어둔 토글 모달 내용 덕분에 여러 확인창 같은 내용을 처리하는데 편하다고 느꼈으며 이런식으로 편리하게 여러 내용에서 재사용할 수 부분이 있다면 더 활용해도 좋다고 생각됨
- 그룹 채팅방 세부 내용에서 하나의 확인창으로 여러 내용을 재사용해 실행하도록 구성했는데, 원래 평소였으면 갯수대로 모두 만들어 구성했을 것 같은데 이번에는 비슷하고 중복된 내용이 반복되는 부분이 많아서 하나로 처리할 수 있었다고 생각됨
