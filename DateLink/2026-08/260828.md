# 오늘 한 일

## 커밋한 내용

- 호스트 권한 위임 관련 오류 수정 및 그룹 채팅 삭제, 나가기 관련 검색창 조건부 추가 및 여러 내용 추가 수정

## 수정 내용

- 호스트가 그룹 채팅 나가고 다른 사용자가 호스트될 때 ID가 문자열로 변환되어 저장되도록 수정
- 채팅방 나가기 버튼 관련 조건부 추가
- 사용자 검색에 조건부를 추가하고 사용자 목록은 조건부를 수정해 텍스트 문구가 출력되도록 구성
- 문제 확인을 위해 추가했던 콘솔 로그 삭제

## 결과

- 호스트가 그룹 채팅 삭제를 클릭하면 검색창이 보이지 않고 기존의 삭제 메시지와 버튼만 보여지는 것을 확인
- 관리자 또는 일반 사용자가 그룹 채팅 나가기를 클릭하면 검색창이 보이지 않고 기존의 메시지와 버튼만 보여지는 것을 확인
- 그룹 채팅 내의 사용자 목록이 1명 밖에 없다면 그룹 채팅 나가기 버튼이 보이지 않는 것을 확인
- 호스트가 그룹 채팅 나가기 버튼을 클릭하고 호스트를 넘길 사용자가 없으면 문구가 보여지며 검색창에서 입력해도 일치하는 사용자가 없으면 또 다른 문구가 보여지는 것을 확인

# 오늘 배운 점

- 그룹 채팅방에 다른 사용자가 있고 그 이후 나가게 되면 그룹 채팅 나가기 버튼이 그대로 보여져 클릭되는데 이 때 별도의 문구가 보여지도록 구성을 했는데 이런 내용처럼 완벽하게 사전에 차단되면 좋지만 안되는 경우 추가 조건부나 내용을 추가해 미리 방지하는 방법이 좋다고 생각됨
