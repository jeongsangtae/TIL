# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 사용자 강제 퇴장 관련 액션 함수, 백엔드 라우터 추가

## 수정 내용

- 사용자 강제 퇴장 관련 액션 함수와 백엔드 라우터
- 사용자 메뉴 확인창 함수에 사용자 강제 퇴장 조건부 추가
- 사용자 강제 퇴장 관련 실시간 반영 로직 추가

## 결과

- 사용자 우클릭 후 강제 퇴장 버튼 클릭 시에 해당 사용자가 관리자 또는 멤버일 시 채팅방에서 강제 퇴장 당하는 것을 확인
- 실시간 반영 로직도 구성했기 때문에 확인했으나 생각한대로 동작하지 않는 것을 확인

# 오늘 배운 점

- 실시간 반영 로직을 동일하게 구성했으나 생각한대로 동작하지 않는 것을 보고 추가 확인이 필요해졌는데 앞에서 동일하게 작동이 되었다고 다른 내용도 똑같이 될 것으로 생각한 내 생각이 틀렸다는 것을 알게 되었다.
- 강제 퇴장 관련 로직과 실시간 반영 로직을 다시 확인하고 다른 내용 실시간 반영되지 않는 부분도 발견해서 이에 대해 다시 확인할 필요성을 느낌

<br />

# 내일 할 일

- 사용자 강제 퇴장 시 홈으로 이동하는 로직 필요
- 사용자 강제 퇴장 시에 실시간 반영되지 않는 로직 확인 필요
- 채팅방 새로 들어온 사용자 온라인/오프라인 유무를 확인하지 않고 바로 오프라인으로 포함되는 내용 확인 필요 (실시간 반영은 작동중)
- 사용자 채팅방 나가기 버튼으로 나갈 시에 실시간 반영되지 않는 부분 확인 필요
- 호스트 권한 위임, 관리자 권한 부여 등 버튼 관련 CSS 수정 필요
- 호스트 그룹 채팅방 나가기 기능 (나가면서 권한 자동 위임까지)
