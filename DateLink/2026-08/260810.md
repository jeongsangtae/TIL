# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 호스트 위임 실시간 반영 추가 및 그룹 채팅 관리자 부여 액션 함수, 백엔드 로직 추가

## 수정 내용

- 호스트 권한 위임 관련 라우터에 실시간 반영 로직 추가
- 관리자 권한 부여 라우터를 추가하고 권한 부여 내용 및 실시간 반영 로직 추가
- 호스트 권한 위임과 관리자 권한 부여 함수 내에 확인을 위한 콘솔 로그 추가
- 그룹 채팅방 목록을 불러오는 내용에 호스트 권한 위임과 관리자 권한 부여 실시간 반영 관련 socket 이벤트 추가
- 관리자 권한 부여 관련 액션 함수 추가

## 결과

- 호스트 권한 위임 시에 호스트가 된 사용자, 호스트를 위임한 사용자, 다른 사용자 화면 모두 실시간 반영되는 것을 확인
- 관리자 권한 부여는 테스트해봤지만 관리자 권한 부여가 아닌 호스트 권한 위임으로 작동되고 있기 때문에 추가 수정 필요

# 오늘 배운 점

- 호스트 권한 위임 로직이 잘 구성되어 있어서 이걸 활용해 관리자 권한 부여 로직까지 쉽게 구현할 수 있었음
- 위 내용과 연장되는 부분인데, 다른 내용을 활용해 구성하는 것도 좋지만 추가 확인을 좀 더 세세하게 해야 한다는 것을 느꼈는데 현재 관리자 권한 부여가 호스트 권한 위임으로 작동되고 있어서 추가로 확인한 뒤 수정해야 하며 비슷한 내용이라도 가져와 구성할 때는 확인을 더 세세하게 해야한다고 확실히 느낌
- 그룹 채팅방 관련 실시간 반영 로직처럼 구성을 미리 잘해놓으면 재사용하기도 쉽고 내용이 추가되어도 간단하게 해결할 수 있어서 앞으로 이런 부분도 고려해 구성하는 것이 좋다고 생각됨
