# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 나가기 확인 관련 함수, 액션 함수 수정 및 그룹 채팅 나가기 관련 백엔드 라우터 수정

## 수정 내용

- 호스트 그룹 채팅 나가기 구분하는 내용 추가
- 새롭게 선택된 호스트 정보를 전달하고 해당 정보를 백엔드로 전달하도록 구성
- 그룹 채팅 나가기 백엔드 라우터에서 새로운 호스트 정보를 확인하고 선택한 사용자를 호스트로 업데이트하는 내용 추가

## 결과

- 호스트가 그룹 채팅방 우클릭 시 호스트 나가기 버튼이 보여지며 해당 버튼 클릭 시 다른 사용자에게 호스트를 넘기는 선택창이 뜨고 선택 후 나가기 버튼을 클릭하면 해당 사용자에게 호스트를 넘기며 채팅방을 나가게 되는 것을 확인
