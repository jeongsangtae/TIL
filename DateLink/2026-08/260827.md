# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 나가기 관련 에러 수정 및 그룹 채팅 나가기 실시간 반영 수정 및 호스트 권한 위임 에러 확인

## 수정 내용

- 호스트가 그룹 채팅 나가고 다른 사용자가 호스트될 때 ID가 문자열로 변환되어 저장되도록 수정
- 프론트엔드의 그룹 채팅 나가기 관련 액션 함수에 그룹 채팅방 업데이트하는 내용 추가
- 문제 확인을 위해 추가했던 콘솔 로그 삭제

## 결과

- 호스트가 그룹 채팅방을 나가면서 선택한 사용자가 호스트로 업데이트되며 패널 내의 정보가 바로 업데이트되는 것을 확인
- 호스트가 다른 사용자에게 호스트 권한 위임하거나 관리자 권한 부여시 에러가 발생하며 정상적으로 작동되지 않는 것을 확인
