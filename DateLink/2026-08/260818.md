# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 사용자 강제 퇴장 네비게이트 로직 수정 및 그룹 채팅 수락 사용자 온라인 유무 확인 추가

## 수정 내용

- 강제 퇴장당한 사용자에게 강제 퇴장 이벤트를 전달하도록 백엔드 소켓 이벤트 추가
- 그룹 채팅 초대 수락한 사용자 온라인 유무를 true로 전달하도록 수정
- 강제 퇴장당한 사용자 홈으로 이동되는 useEffect 추가

## 결과

- 사용자가 강제 퇴장당하면 홈으로 이동되고 채팅방이 그룹 채팅방 목록에서 사라져 보이지 않는 것을 확인
- 그룹 채팅에 참여하지 않고 강제 퇴장당할 경우 그룹 채팅방 목록에서 해당 채팅방이 사라지지 않고 남아있는 것을 확인
- 그룹 채팅 초대를 수락하면 해당 사용자는 바로 온라인 목록에 포함되어 보여지는 것을 확인

# 오늘 배운 점

- 프론트엔드 소켓 이벤트 관련 내용을 Zustand 액션 함수에서만 구성해 사용했었는데 이번에 일반 컴포넌트 내에서 구성해 사용해보면서 이런 방식도 할 수 있는 것을 알게 되었다.
- 강제 퇴장관련 내용을 구성하면서 생각보다 구조와 여러 수정할 내용이 많다는 것을 다시 한 번 느꼈고 해당 내용을 추가하게 되면서 다른 내용 문제도 확인하게 되어 좋은 기회였다고 생각됨
