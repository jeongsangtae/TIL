# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 사용자 강제 퇴장 관련 소켓 이벤트 수정 및 그룹 채팅 나가기, 나갈 시 초대 목록 삭제 관련 소켓 이벤트 수정 및 사용자 강제 퇴장 네비게이트 로직 테스트

## 수정 내용

- 그룹 채팅방 초대 목록 실시간 반영해 제거하는 백엔드 로직 수정
- 채팅방 나간 사용자를 사용자 목록에서 실시간으로 제거하는 백엔드 로직 수정
- 강제 퇴장당한 사용자 화면에서 홈으로 이동하는 로직을 테스트하고 주석 처리
- 그룹 채팅 사용자 강제 퇴장 관련 실시간 반영 프론트엔드 로직 위치 변경 및 수정

## 결과

- 그룹 채팅방 나갈 시 다른 사용자 화면에서 실시간 반영되어 해당 사용자가 사용자 목록에서 보이지 않는 것을 확인
- 그룹 채팅방에서 사용자가 나가면 해당 사용자와 채팅방 관련된 초대 목록을 나간 사용자, 초대한 사용자 화면에서 모두 실시간 반영되어 사라지는 것을 확인
- 강제 퇴장당한 사용자 화면이 홈으로 이동하긴 하지만 채팅방에 참여하고 새로고침했을 때도 홈으로 이동해버리는 문제가 발생하면서 새롭게 추가한 로직은 원하는 대로 동작하지 않는 것을 확인
- 사용자 강제 퇴장 시에 실시간 반영되어 남아있는 사용자 화면에서는 실시간 반영되는 것을 확인

# 오늘 배운 점

- 내용을 수정하면서 연관된 내용을 바로 찾아서 함께 수정하지 않으면 문제가 발생한 지 알 수 없기 때문에 바로 함께 수정하는 것이 추가 오류 생기는 것을 방지할 수 있다고 생각하게 됨
- 로직을 구성할 때 간결하게 구성하는 것만 생각하고 여러 문제를 고려하지 않으면 생각한 것과 다르게 원하는 결과를 얻을 수 없다는 것을 다시 한 번 느낌
- 강제 퇴장 같은 로직은 브라우저가 실행되는 내용도 생각을 잘해야 하는데, 현재 문제처럼 다른 사용자의 브라우저 UI를 직접 변경할 수 없기 때문에 이런 사항들까지 고려해 로직을 구성하는 것이 중요하다고 생각됨
