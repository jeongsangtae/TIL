# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 수정 관련 조건부 수정 및 프롭스, 타입, 백엔드 조건부 수정

## 수정 내용

- 백엔드 내의 그룹 채팅방 수정 권한 조건부 수정
- 사용자 목록 관련 정보를 프롭스로 내리고 사용자 역할 정보를 저장해 조건부로 사용하도록 수정
- 채팅방 수정, 삭제, 나가기 조건부를 수정해 수정은 관리자와 호스트 모두 변경할 수 있도록 구성
- 타입 정의 수정

## 결과

- 관리자 권한으로 그룹 채팅방 제목 수정 시에 에러 발생없이 수정되는 것을 확인
- 관리자 권한으로 그룹 채팅방 우클릭 시 삭제 버튼은 출력되지 않는 것을 확인
- 호스트 권한으로 그룹 채팅방 우클릭 시 나가기 버튼은 출력되지 않는 것을 확인

# 오늘 배운 점

- 현재 구성된 구조에 맞춰 데이터를 정리해 프롭스를 내릴지 또는 프롭스를 내리고 데이터를 정리할 지 선택을 해야 하는데 이 선택에서 구조를 복잡하게 수정해야 하고 코드가 어지럽게 구성이 된다면 최대한 간편하고 간단한 구조로 구성하는 것이 맞는 것을 알게 됨
- 관리자 권한을 어디까지 허용할 지 많은 고민을 했는데 채팅방 삭제는 관리자가 처리하기엔 부적절하고 수정까지만 하는 것이 맞다고 생각되어 삭제 기능은 추가하지 않았는데 이처럼 권한 관련해서 적절한 범위를 설정하는 것도 중요하다고 생각됨
