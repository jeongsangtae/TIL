# 오늘 한 일

## 커밋한 내용

- 그룹 채팅 사용자 오버레이 타입 관련 내용 추가 및 구조 수정

## 수정 내용

- 그룹 채팅방 세부 내용에 오버레이 타입 관련 useState 추가
- 사용자 프로필 열고 닫는 함수를 수정해 현재 열린 오버레이 타입 내용 추가
- 사용자 프로필 열고 닫는 함수 이름을 변경하고 해당 내용을 하위 컴포넌트로 전달
- 그룹 채팅방 내의 사용자, 패널에서 사용자 우클릭 시 컨텍스트 메뉴 열리도록 구성
- 그룹 채팅방 내의 사용자, 패널에서 사용자 좌클릭 또는 우클릭 시 관련 정보를 상위 컴포넌트로 전달하도록 구성

## 결과

- 좌클릭 시에 기존 내용과 동일하게 작동하는 것을 확인
- 컨텍스트 메뉴 관련 내용은 구성되지 않아 클릭 시 단순히 창만 닫히는 것을 생각했으나, 사용자 프로필이 열리는 것을 확인

# 오늘 배운 점

- 좌클릭과 우클릭 구분을 조금 어렵게 생각했는데 의외로 단순하게 조건 하나를 추가해 해결할 수 있는 것을 배움
- 우클릭 관련 컨텍스트 메뉴를 그룹 채팅방 사용자 컴포넌트에 그대로 구성하려고 했으나, 내부에 구성하면 너무 복잡해 별도의 컴포넌트에 구성하는 것이 좀 더 깔끔한 것을 알게 됨
