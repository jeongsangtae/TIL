# 오늘 배운 점

- useNavigate 같은 내용도 ESLint가 요구하면 useEffect 의존성 배열에 포함시킬 수 있고 React Router 공식 예제나 ESLint 규칙에도 맞는 방식인 것을 알게 됨
- useNavigate는 React Router에서 안정적인 함수를 반환해 참조 시에 매 렌더마다 바뀌지 않는 것도 배움
- AI 프롬프트를 어떤 내용으로 구성해야 하는지 대략적인 틀을 배움
