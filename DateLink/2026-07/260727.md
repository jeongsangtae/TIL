# 오늘 배운 점

- GitHub Actions를 이용한 CI 테스트 구성 과정을 경험하면서 CI 동작 방식 이해
- Zustand Store에서 사용하는 함수도 useEffect 의존성 배열에 포함하는 것이 ESLint 규칙에 맞다는 것을 알게 됨
- 의도적으로 의존성을 제외해야 하는 경우에는 eslint-disable 주석을 사용할 수 있다는 점을 배움
- any 대신 unknown이나 object 같은 적절한 타입을 사용하는 것이 타입 안정성 측면에서 더 좋은 것을 다시 확인
