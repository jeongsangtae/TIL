# 오늘 느낀 점

- README 내의 여러 내용에서 수정이 필요한 내용은 조금 더 수정해 읽기 쉽도록 만들고 아직 구성하지 않은 내용은 간결하게 수정해 추후 추가 예정으로 구성해주었으며 주요 기능 내의 그룹 채팅 항목을 살펴보며 호스트 권한 관련 내용이 추가될 필요가 있다고 생각되어 추후 구현 예정에 호스트 권한 관련 내용을 추가해주었다. 호스트 권한을 위임하는 기능과 호스트가 채팅방을 삭제하는 것이 아닌 나갈 수도 있는 기능 그리고 나갈 시에 자동으로 권한을 위임하거나 위임할 사용자를 선택하고 나가도록 하는 기능 추가로 채팅방에서 특정 사용자를 강제 퇴장하는 기능을 추가할 예정이며 해당 기능을 구현하면 Render와 MongoDB Atlas를 사용해 서비스 배포하고 Electron 기반으로 데스크톱 앱 지원도 하도록 구현할 생각이다. 호스트 관련 기능을 배포하고 구현해도 되긴 했지만, 권한 관리 같은 기능과 예외 상황까지 고려를 했을 때 배포 전에 추가해두는 방향이 옳다고 생각되어 먼저 기능 추가 한 후 배포를 진행할 예정이다.
